# expectations/print-scope.txt — WPT css/ areas that matter for paged output.
#
# Format: one `css/<area>/` directory prefix per line.
# Lines starting with '#' are comments. Empty lines are ignored.
#
# The WPT dashboard (`generate-dashboard`) uses these areas as the
# denominator of the in-scope pass rate. Areas without meaning for print are
# listed in known-issues.txt instead, with a reason. Areas outside the print
# scope whose results are still tracked are listed in tracked-areas.txt. An
# area may appear in only one of the three files; an area in none of them is
# reported as unclassified.
