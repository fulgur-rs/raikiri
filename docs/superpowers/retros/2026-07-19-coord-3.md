## Signals (5)

### S1. Codex sandbox-aware prompt discipline — largest efficiency delta this sprint

Sprint's most consequential observation. During yxq's §8.3, the default codex prompt included expectations that led the Codex agent to attempt `cargo` re-runs inside the sandbox. Sandbox is read-only for cargo target dirs (correctly, by design) → exit 101 loop → Codex worker eventually silent-died at 46 minutes with no assistant-message correction (app-server "running" status remained; PID had exited).

Coord side detected the death via PID-liveness heuristic (`ps -p <pid>` + `/proc/<pid>` existence + log-tail mtime staleness), issued `/codex:cancel` to clean state, then re-dispatched with a **sandbox-aware** prompt: "mechanical checks (fmt/clippy/test) are already verified on coord side; delegate only spec / quality / scope judgment; file reads only; do not attempt cargo re-runs." Result: 1m 28s GATE PASS.

Absolute delta: **46 min silent-death vs 1m 28s success** on the same review. This is the single most efficiency-affecting rule-improvement candidate this sprint.

**Rule-improvement scope**: `gate.md §8.3` needs an §8.3.2-style subsection ("Sandbox-aware Codex final-review prompt discipline") documenting the prompt shape. Filed as **decision D1** below.

**Companion concern** (not the same decision): the death-detection heuristic itself (S2) is a coordinator responsibility — different rule file, different decision.

### S2. Codex worker liveness — coordinator PID heuristic

The 46-min silent-death was detectable because coord side ran `ps -p <pid>` + `/proc/<pid>` existence + log-tail-mtime staleness checks. Without those, the coord would have polled a stale "running" status indefinitely.

Codex app-server's own worker-liveness tracker does not update on silent SIGABRT / abrupt exit. Coord side must supplement.

**Rule-improvement scope**: `agent-map.md` §coordinator responsibilities (or `gate.md §8.3` as a companion note to D1). Filed as **decision D2** below with two candidate rule homes for human approver to pick.
