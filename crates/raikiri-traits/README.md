# raikiri-traits

Shared DOM, resource, layout and target resolution contracts: the traits and neutral model types that the other raikiri crates are written against. This crate contains no implementations.

raikiri is a Rust HTML/CSS paged layout and rendering foundation, developed to
replace the layout engine of [Fulgur](https://github.com/fulgur-rs/fulgur).
`raikiri-traits` is one of the crates that Fulgur builds on. The 0.0.x releases make no
promise of API stability: any release may change the public API.
