# raikiri-layout-geometry

Geometry and box-layout result types shared by the layout engine and its consumers: sizes, points, edges and the placement of a box.

raikiri is a Rust HTML/CSS paged layout and rendering foundation, developed to
replace the layout engine of [Fulgur](https://github.com/fulgur-rs/fulgur).
`raikiri-layout-geometry` is one of the crates that Fulgur builds on. The 0.0.x releases make no
promise of API stability: any release may change the public API.
