# raikiri-net

`NetworkProvider` and `ReplacedResolver` implementations, including an SSRF-safe HTTP provider (feature `http-ureq`) and a provider for trusted networks.

raikiri is a Rust HTML/CSS paged layout and rendering foundation, developed to
replace the layout engine of [Fulgur](https://github.com/fulgur-rs/fulgur).
`raikiri-net` is one of the crates that Fulgur builds on. The 0.0.x releases make no
promise of API stability: any release may change the public API.
