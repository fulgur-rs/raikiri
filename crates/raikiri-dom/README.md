# raikiri-dom

The DOM data model, the layout engine (Taffy block layout and the shodo inline engine) and the runtime side of paged-media (GCPM) support.

raikiri is a Rust HTML/CSS paged layout and rendering foundation, developed to
replace the layout engine of [Fulgur](https://github.com/fulgur-rs/fulgur).
`raikiri-dom` is one of the crates that Fulgur builds on. The 0.0.x releases make no
promise of API stability: any release may change the public API.
