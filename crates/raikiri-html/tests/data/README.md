# Bundled test font

`NotoSansTest-Regular.ttf` is Noto Sans Test Regular, version 1.002.
It tests consumer-supplied font registration without system font discovery.
The font's embedded copyright notice is:

> Copyright 2022 Google Inc. All Rights Reserved.

The embedded license declaration specifies the SIL Open Font License 1.1.
The license is included in `OFL.txt`, copied from the
[Noto Test project](https://github.com/notofonts/test/blob/53e3ecf368846108245e4792f0ee7505fe6d8a1a/OFL.txt).

## Provenance

- Official distribution: [Noto Sans Test, unhinted TTF](https://notofonts.github.io/test/fonts/NotoSansTest/unhinted/ttf/NotoSansTest-Regular.ttf).
- Fixture SHA-256: `70f6f780859bd7ccdb61fe01d6d1ffa9d3cc38f54758071c2ba339f96b328224`.
- Compared distribution SHA-256: `f7e3db73a8ef628b4bf356b93590d30ed8339bb64373afcefc6fd643ac5916b3`.

timestamp and checksum adjustment. The fixture's original build revision is
unknown; its bytes are preserved.
